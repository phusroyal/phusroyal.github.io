# Design Tokens

Use this palette for every site surface. Keep color choices semantic: reference the appropriate CSS variable instead of adding new hard-coded values.

## Shared Foundation

| Token | Hex | Use |
| --- | --- | --- |
| Limestone | `#F1ECE3` | Page background |
| Paper | `#FBF8F2` | Cards and reading surfaces |
| Walnut | `#2D2722` | Primary text |
| Taupe | `#74695D` | Supporting text |
| Sand | `#D8CCBC` | Borders and dividers |
| Warm walnut | `#5A4032` | Navigation and dark chrome |
| Cognac | `#7A5237` | Links and primary actions |
| Dark walnut | `#5D3D2A` | Hover and active states |
| Cream | `#FFF9EF` | Text on dark surfaces |
| Brass highlight | `#E0AF7C` | Active and hovered navigation links |

## Interactive Extension

Use these only inside interactive publication and Writing demos: dark panel `#302823`, bright cognac `#A06B43`, brass `#B49357`, clay `#A86650`, moss `#70785E`, and oat `#C6A98D`. In dark mode, use the corresponding theme variables: night walnut `#181311`, cognac `#C99062`, brass `#D2B36E`, clay `#C97A60`, moss `#899174`, and oat `#D8BCA3`.

Do not introduce neon cyan, pink, blue, or unrelated color values. Maintain readable text contrast on paper and dark panel surfaces.
